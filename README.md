# 商业数据分析实验 · Python 迁移版

把《CDA 一级认证教材：商业数据分析（第 4 版）》里原本用 **Excel/WPS 和 Power BI** 完成的商业分析案例，理解其项目内涵后，用 **Python** 等价重做一遍。

目标不是把 Excel 的点击步骤翻译成代码，而是保留原案例的**业务问题、分析路径、指标口径和结论**，用可复现的脚本替代手工操作。

## 为什么做这件事

教材中的案例大多依赖 GUI 操作（数据透视表、Power BI 预测面板），结论正确但过程不可审计、不可批量复现。迁移到 Python 后：

- 指标计算过程可追溯，口径写死在代码里
- 数据更新后一键重跑，不需要重新拖拽图表
- 同一套代码可扩展到真实业务数据量级

## 目录结构

```
T/
├─ README.md
├─ 实验清单.md                 # 教材 → Python 迁移对照表
├─ requirements.txt
├─ data/
│  ├─ raw/                     # 原始下载数据（不入库）
│  └─ processed/               # 中间宽表
├─ src/
│  ├─ common/config.py         # 路径、中文字体、图表落盘
│  └─ lab01 … lab12/           # 每个实验独立入口
└─ output/
   ├─ figures/                 # 图表
   └─ tables/                  # 结果表
```

## 快速开始

```bash
# 建议 Python 3.10+
pip install -r requirements.txt

# 运行任意一个实验（在 T/ 根目录）
python src/lab01/main.py
```

每个实验的产物会写入 `output/figures/labXX_*.png` 和 `output/tables/labXX_*.csv`。

## 数据来源与声明

教材未随 PDF 附带案例源数据，因此：

- **公开数据**：KDD99 银行数据集（实验 08/09/12）、AirPassengers（实验 10）首次运行时尝试下载并缓存；
- **书中数值**：实验 06/07/11 直接使用教材表格中的数值，结果应与原文一致；
- **模拟还原**：实验 01-05 依据教材给出的结论与比例反向构造数据，固定随机种子，仅用于复现分析方法，**不代表原始业务数据**。

各实验 README 会明确标注自己属于哪一类。

## 关于"教材中的 Python 代码"

本书为 CDA 一级认证教材，全书案例载体只有 Excel/WPS 和 Power BI，**不含 Python 代码，也没有配套 ipynb**（已检查 PDF 内嵌附件，数量为 0）。因此本项目直接承担"把教材实验转成 .py"的角色，每个实验都是一个可独立运行的 Python 脚本。

## 说明

- 代码为基于教材方法论的独立实现，不复制教材原文与图表。
- 商业分析结论受数据口径影响，本项目所有图表均注明数据性质（真实/书中数值/模拟）。
