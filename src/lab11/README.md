# lab11 业务假设驱动的信用卡日度消费预测

- **教材出处**：第 10 章 10.3 时间序列预测（PDF p303-307，Excel 实现）
- **迁移目标**：把"先提业务假设 → 分组均值预测 → 实际值检验 → 滚动修正"这套 Excel 分析流程，用可复现的 Python 规则模型实现，并逐日核对书中数值。
- **数据**：教材正文已给出 2013-03-03 ~ 03-16 两周每日消费额（万元），直接录入（`data_prep.py`），不做模拟。

## 1. 业务问题与教材口径

银行只有第一周（03-03 ~ 03-09）的日消费额，要预测第二周（03-10 ~ 03-16）。教材不用回归模型，而是先判断"哪几天的消费行为相似"，用同类日期的均值作预测：

| 假设 | 内容 | 代码落点 |
|---|---|---|
| H1 | 周日、周一、周五消费水平相近 → 平稳日 | `GROUPS` |
| H2 | 周二、周三、周四消费水平相近 → 低谷日 | `GROUPS` |
| H3 | 周六是消费高峰，周五是高峰前奏 → 取最近一个周五与周六的均值 | `fit()` 的 `peak` |
| H4 | 妇女节是一次性事件，抬高了节后峰值，不进入常态基线 | `holiday_effect()` |
| H5 | 每周滚动：用新一周实际值重估分组均值，修正下一周预测 | `main()` 滚动段 |

首轮三个基准值：

- 平稳日 = (183.49 + 182.75 + 182.08) / 3 = **182.77**
- 低谷日 = (174.73 + 177.70 + 177.08) / 3 = **176.50**
- 高峰日 = (182.08 + 239.16) / 2 = **210.62**

## 2. 结果与教材核对

首轮预测与教材 p305-306 的 7 个预测值**逐日完全一致**（容差 0.01，代码内有断言）：

| 日期 | 星期 | 分组 | 实际 | 预测 | 误差 |
|---|---|---|---|---|---|
| 03-10 | 周日 | 平稳日 | 188.17 | 182.77 | +5.40 |
| 03-11 | 周一 | 平稳日 | 191.31 | 182.77 | +8.54 |
| 03-12 | 周二 | 低谷日 | 174.99 | 176.50 | -1.51 |
| 03-13 | 周三 | 低谷日 | 175.14 | 176.50 | -1.36 |
| 03-14 | 周四 | 低谷日 | 171.66 | 176.50 | -4.84 |
| 03-15 | 周五 | 平稳日 | 174.31 | 182.77 | -8.46 |
| 03-16 | 周六 | 高峰日 | 196.42 | 210.62 | -14.20 |

首轮误差：**MAE = 6.33、RMSE = 7.59、MAPE = 3.41%、BIAS = +2.35**（整体略高估）。

妇女节效应按教材口径：

```
(182.77 - 174.31) + (239.16 - 196.42) = 8.46 + 42.74 = 51.20
```

与书中 **51.20** 一致。可以看到节日效应主要释放在节后周六（42.74），周五当日仅 8.46。

## 3. 滚动修正

用两周 14 天数据重估分组均值：

- 平稳日 **183.68**、低谷日 **175.22**、高峰日 **185.37**（高峰日不再被 239.16 的节日峰值拉高）。

修正后的第三周（03-17 ~ 03-23）预测：周日/周一/周五 183.68，周二至周四 175.22，周六 185.36。

修正效果：对第 2 周的回看 MAE 从 6.33 降到 5.20（MAPE 3.41% → 2.80%）。**注意这是样本内回看**（第 2 周实际值参与了重估），仅用于说明修正方向；第三周没有实际值，无法做样本外评估。

## 6. 迁移说明与局限

- 教材的方法本质是**规则化预测 + 人工假设**，不是统计模型；本迁移保留这一内涵，没有替换成 ARIMA/回归，否则会丢失"业务假设驱动"的教学重点。
- 分组口径来自书中文字描述与数值反推（三组均值恰好复现 182.77 / 176.50 / 210.62），已用断言固定，后续改动会立即暴露。
- 第三周预测依赖"日消费水平短期稳定"这一前提；遇到新的节假日或营销活动需重新走 H4 的识别流程。
