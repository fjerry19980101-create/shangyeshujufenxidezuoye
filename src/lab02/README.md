# lab02 广告与销售漏斗分析

## 一、教材出处与业务背景

- 教材：第 2 章 2.1.2 链式分析（PDF p61-70），原案例用 Excel 漏斗图完成。
- 业务背景：某公司大力推广一款新产品，投了大量资源但效果平平，需要找到影响转化的瓶颈环节，把预算用在刀刃上。
- 关键上下文：项目整体转化率只有 **1.08%**，而相似成熟产品广告曝光转化率均值 **5%**、最高 **15%**，低了近 4 个百分点。

## 二、教材口径（必须一致）

用户行为路径与四个环节转化率：

```
广告触达 → 查看广告 → 跳转商品介绍页 → 点击立即购买 → 购买成功
              10%           20%              60%            90%
```

| 环节 | 教材转化率 | 行业均值 | 行业最高 |
|---|---|---|---|
| 触达转化率（查看/触达） | 10% | 20% | 35% |
| 跳转转化率（详情页/查看） | 20% | 50% | 65% |
| 购买意愿转化率（点击购买/详情页） | 60% | — | — |
| 购买转化率（支付成功/点击购买） | 90% | — | — |
| **总体转化率（购买成功/触达）** | **1.08%** | 5% | 15% |

教材结论：跳转环节是最大瓶颈（广告页过长，"了解详情"按钮要下拉好几屏）；
触达环节次之（推送标题/人群/时间不匹配）。两项同时提升后总体可达 **5.4%**，
针对性改进落地后实际为 **5.2%**。

## 四、数据说明

教材只给出转化率、未附曝光明细，因此漏斗人数按书中口径构造：

- 原始漏斗：触达 1,000,000 → 查看 100,000 → 详情页 20,000 → 点击购买 12,000 → 支付成功 10,800；
- 改进后漏斗：触达 1,000,000 → 查看 200,000 → 详情页 100,000 → 点击购买 60,000 → 支付成功 52,000（对话教材"实际 5.2%"）。

**以上为按书中比例构造的演示数据，不代表原始投放明细。**

## 六、运行结果（与教材对照）

| 指标 | 计算结果 | 教材值 | 说明 |
|---|---|---|---|
| 原始总体转化率 | 1.08% | 1.08% | ✅ 完全一致 |
| 跳转提升至 50% 后 | 2.70%（+1.62pp） | +1.7pp | ✅ 教材为约数 |
| 触达提升至 20% 后 | 2.16%（+1.08pp） | +1pp | ✅ 教材为约数 |
| 双提升（触达 20%+跳转 50%） | 5.40% | 5.4% | ✅ 完全一致 |
| 改进实施后总体转化率 | 5.20% | 5.2% | ✅ 完全一致 |

结论与教材一致：

1. **瓶颈定位**：跳转转化率仅 20%（行业均值 50%），触达转化率仅 10%（行业均值 20%），
   两项合计造成与行业均值约 3.9 个百分点的差距；
2. **收益排序**：跳转环节提升带来 +1.62pp，高于触达环节的 +1.08pp，应优先改造广告页；
3. **改进方案**：广告页"了解详情"按钮改为滑动悬浮（不管看哪一屏都能进详情页），
   并参考高转化标题文案迭代 4 个版本；落地后总体转化率 5.2%，与行业持平。
