# lab05 用户细分与营销评估

## 一、教材出处与业务背景

- 教材：第 3 章 3.5.2 电商平台的客户个性化营销示例（PDF p118-122），原案例用 Excel 完成。
- 业务背景：某国外多品类电商平台下月要做大型促销，出于活动流程与预算考虑，只面向"男性或女性"中的一类人群，目前缺乏具体营销人群与促销方向。
- 分析需求：用数据分析帮助平台制定具体的促销策略，实现精准营销。

## 二、教材口径与分析路径

教材采用"明确重点 → 因果（画像）分析 → 验证想法"三步：

1. **明确分析重点**：先看购买客户性别分布，女性占 **60%**、男性 40%，人群规模更大 → 促销面向女性；
2. **因果分析（用户画像，逐层聚焦）**：
   - 女性年龄段：18-25 岁 17%、26-35 岁 20%、36-49 岁 27%、**50 岁以上 36%** → 选 50 岁以上；
   - 50 岁以上女性品类：**服饰 + 护肤品**为主 → 选品西服 + 抗老面霜；
   - 50 岁以上女性支付方式：按支付宝/银行卡/微信分布 → 设计差异化满减
     （支付宝满 150 减 30、银行卡满 200 减 50、微信满 300 享八折）；
3. **验证想法（A/B 测试）**：
   - 测试组：50 岁以上女性 + 购买服饰/护肤品；
   - 对照组：50 岁以上女性 + 购买其他品类；
   - **两组规模必须一样大**；
   - 评估指标：活动参与人数、参与率、转化人数、转化率、新增用户数、新增活跃用户数。

活动主题："50 岁优雅"；活动仅推送给测试组。

## 三、Python 迁移思路

| Excel 操作 | Python 等价实现 |
|---|---|
| 性别/年龄/品类/支付方式占比 | `value_counts(normalize=True)` + 单变量分布图 |
| 逐层筛选目标人群 | 布尔索引链式过滤 |
| A/B 分组随机抽样 | `sample(n=...)` + 固定 `random_state` |
| 六项活动指标 | 分组 `sum()` 后计算比率 |
| 结果对比图 | 分组柱状图（比率 + 人数） |

## 四、数据说明

教材未附源数据，本实验按书中比例反向构造（固定随机种子 2024）：

- 12,000 名购买客户，女 7,200（60%）/ 男 4,800（40%）；
- 女性年龄：17% / 20% / 27% / 36%（精确配比）；
- 50 岁以上女性品类：服饰 40%、护肤品 30%、食品 12%、电子产品 10%、家居 8%；
- 支付方式：支付宝 45%、银行卡 30%、微信 25%；
- 测试组与对照组各 777 人；测试组参与 272（35.0%）、转化 33（12.1%），
  对照组参与 23（3.0%）、转化 2（8.7%）。

**数据为模拟还原，不代表平台真实交易。**

## 六、运行结果（与教材对照）

| 教材结论 | 模拟结果 | 是否复现 |
|---|---|---|
| 女性占 60% | 7,200 / 12,000 = 60% | ✅ |
| 女性中 50+ 占 36% | 2,592 / 7,200 = 36% | ✅ |
| 50+ 女性以服饰、护肤品为主 | 服饰 40% + 护肤品 30% = 70% | ✅ |
| 支付方式清晰可分 | 支付宝 45% / 银行卡 30% / 微信 25% | ✅ |
| 两组等规模 | 各 777 人 | ✅ |
| 测试组指标显著优于对照组 | 参与率 35.0% vs 3.0%；转化率 12.1% vs 8.7%；新增 25 vs 8；新增活跃 18 vs 5 | ✅ |

> 教材未给具体销售额与参与数值，本实验核对的是**画像比例、分析路径与 A/B 结论方向**。
