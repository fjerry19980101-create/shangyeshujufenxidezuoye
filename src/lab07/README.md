# lab07 指标归因：价值树拆解与贡献度

## 一、教材出处与业务背景

- 教材：第 5 章 5.3.3 归因分析（PDF p175-186），原案例用 Excel 完成。
- 业务问题：某产品营收从 11000 降至 9975，需要判断订单数与单价各自的影响，找到核心因素后指导运营动作。

## 二、教材口径（书中数值，直接录入）

### 1. 加/减法拆解

上期 A1=4000、A2=5600、A3=1200、A4=1200，合计 12000；本期 A1=4000、A2=4000、A3=1000、A4=1000，合计 10000。

- 变化量贡献度 = 各指标增量 / 总增量（-2000）→ 0%、80%、10%、10%；
- 变化率贡献度 = 各指标增量 / 上期总值（12000）→ 0%、-13.33%、-1.67%、-1.67%，合计 -16.67%。

### 2. 乘法拆解

营收 = 订单数 × 单价：110 × 100 = 11000 → 105 × 95 = 9975（-1025，-9.32%）。

- **替换法**：订单贡献 = 105×100 - 11000 = **-500**；单价贡献 = 110×95 - 11000 = **-550**；
  合计 -1050，与实际差 +25（交互项），故替换法只能看影响程度，不能精确闭合；
- **LMDI**：贡献占比 = ln(本期/上期) / ln(本期总值/上期总值)
  → 订单 47.56%（-487.5）、单价 52.44%（-537.5），合计正好 -1025。

### 3. 双因素法（比率指标）

整体下单转化率 50% → 27%（-23pp）：

- 波动贡献 A =（产品本期转化率 - 上期转化率）× 产品上期结构占比；
- 结构贡献 B =（本期结构占比 - 上期占比）×（产品本期转化率 - 整体上期转化率）；
- 产品 1：A -10.0% + B -5.0% = C **-15.0%**；
- 产品 2：A -10.0% + B +1.7% = C **-8.3%**。

## 六、运行结果（与教材对拍）

| 指标 | 计算结果 | 教材 |
|---|---|---|
| 营收变化 | 11000 → 9975，-1025（-9.32%） | 一致 |
| 替换法：订单 / 单价 | -500 / -550，合计 -1050 | 一致 |
| 交互项 | +25 | 一致 |
| LMDI 占比 | 47.56% / 52.44% | 一致（书中 47.56%/52.44%） |
| LMDI 金额 | -487.5 / -537.5，合计 -1025 | 一致 |
| 加法变化率贡献 | 0 / -13.33% / -1.67% / -1.67%，合计 -16.67% | 一致（-16.7%） |
| 双因素 C：产品1 / 产品2 | -15.0% / -8.3% | 一致 |

结论：
1. 营收下降 1025 元，订单数（-500）与单价（-550）影响接近，单价略大；
2. 替换法直观但有 25 元交互项未分配，LMDI 可精确闭合，二者方向一致；
3. 双因素法显示产品 1 是转化率下滑主因（-15.0%），产品 2 的结构变化部分抵消了波动（+1.7%）；
4. 归因后需回到业务：订单数看流量/渠道，单价看折扣/商品结构，结合二八法则聚焦核心因素。
