# lab04 财务费用杜邦拆解

## 一、教材出处与业务背景

- 教材：第 3 章 3.4.2 财务费用趋势分析示例（PDF p110-115），原案例用 Excel 实现。
- 业务背景：某零售连锁企业 2020 年 6、7 月财务报告显示总财务费用波动，盈利能力承压。
- 分析需求：分析 7 月财务费用高涨的具体原因，并给出解决办法。

## 二、教材口径与分析路径

教材用杜邦分析"层层拆解"的思路，共三层：

1. **第一层（总体）**：6 月 vs 7 月总财务费用，7 月比 6 月高 **5%**；
2. **第二层（三大期间费用）**：管理费用**显著增长**、销售费用小幅增长、财务费用小幅下降，
   核心问题定位到管理费用；
3. **第三层（管理费用明细）**：**培训与发展、咨询费**两项环比增长超过 **5%**。

业务归因（教材访谈结论）：

- 培训与发展：各地培训需求激增，需持续 1~2 年，外部高级讲师费用增加 → **长期因素**；
- 咨询费：总部人力资源数字化项目 7 月临时外采，交付即结束 → **临时需求**，后续优化可忽略。

优化建议（仅针对培训与发展）：优化差旅政策、采用在线培训、与培训机构谈批量折扣；
执行 3~6 个月后从费用变化、培训满意度、业务绩效三方面复盘。

## 四、数据说明

教材未附费用明细金额，本实验按书中比例反向构造（固定数值，无需随机）：

- 6 月总费用 1,580,000 元 → 7 月 1,659,000 元，环比 **+5.0%**；
- 管理费用 620,000 → 700,000（+12.9%，贡献总增量 101.3%）；
- 销售费用 560,000 → 574,000（+2.5%，贡献 17.7%）；
- 财务费用 400,000 → 385,000（-3.7%，贡献 -19.0%）；
- 管理费用明细中仅培训与发展（+44.4%）、咨询费（+87.5%）超过 5%。

**数据为模拟还原，不代表企业真实账目。**
