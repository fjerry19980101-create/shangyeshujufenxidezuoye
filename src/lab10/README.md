# lab10 航空客运量：效应分解与预测

## 一、教材出处与业务背景

- 教材：第 10 章 10.2 效应分解法（PDF p296-303），原案例用 **Power BI** 的分解预测。
- 业务问题：航空客运量有长期增长与年度季节性（夏季高峰），需要拆开趋势与周期，判断乘法模型是否比加法更贴合，并预测未来 24 个月。
- 教材模型：加法 `yt = Tt + St + Rt`、乘法 `yt = Tt × St × Rt`；趋势用线性/分段，周期用傅里叶级数，MSE + L-BFGS 优化。

## 二、Python 迁移思路

| 教材（Power BI） | 本实验（Python） |
|---|---|
| 效应分解可视化 | `statsmodels.seasonal_decompose`（加法/乘法）四层分解图 |
| 趋势项 | 二次多项式趋势（比纯线性更贴合增长曲线） |
| 周期项（傅里叶） | 年度周期 12 个月，K=5 阶 sin/cos 项 |
| MSE + L-BFGS | 最小二乘闭式解（同一损失函数，结果等价） |
| 加法 → 取对数做乘法 | `log(y)` 建同结构模型，预测后 `exp` 还原 |
| 95% 置信区间 | 残差标准差 + 设计矩阵解析预测方差 |

## 五、运行结果

**分解**：加法分解季节项振幅约 117.4，随机项标准差约 19.3；趋势为平滑上升曲线。

**回测（前 120 期训练 / 后 24 期测试）**

| 模型 | MAE | RMSE | MAPE | 平均 95% 区间宽度 |
|---|---|---|---|---|
| 加法 | 31.2 | 38.6 | 6.86% | 88.2 |
| 乘法（log） | **15.8** | **21.8** | **3.51%** | 97.6 |

**未来 24 个月预测（1961-01 起）**：加法 474.9、乘法 452.3（1 月）；
两种模型均显示 7-8 月为高峰，乘法模型因考虑"波动随规模放大"，长期预测更保守。

**结论**
1. 客运量指数增长、季节振幅随规模扩大，乘法模型更贴合；
2. 取对数后建加法模型，回测 MAPE 3.51%，明显优于加法模型的 6.86%；
3. 两种模型 95% 区间宽度接近（全期约 101 vs 110）；教材在 Power BI 中演示乘法区间更窄，
   差异来自趋势项与区间算法（本实验用二次趋势 + 解析预测方差），不影响"乘法精度更优"的结论；
4. 运营上应在 7-8 月前安排运力与票价，淡季做促销填谷。
