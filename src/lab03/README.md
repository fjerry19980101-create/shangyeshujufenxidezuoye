# lab03 收入趋势与同比归因

## 一、教材出处与业务背景

- 教材：第 3 章 3.4.1 企业收入趋势分析示例（PDF p105-109），原案例用 Excel 透视表完成。
- 业务背景：某线上超市平台自 2017 年运营，管理层需要对 2017-2020 年各省份每月销售数据做全面分析。
- 分析需求：找到收入增长趋势，如果增长不理想，定位问题点并给出业务建议。

## 二、教材口径与分析路径

教材采用"宏观 → 月度 → 同比 → 地域 → 业务归因"的逐层下钻：

1. **年度趋势**：2017 年起每年增长良好，宏观上看不出异常；
2. **月度趋势**：切到 2020 年，下半年增长明显放缓；
3. **同比分析**：2020 年 9-11 月不理想，**11 月出现负增长**；
4. **地域维度**：2020 年 11 月**多个省份负增长**，选取四川省重点分析；
5. **省份下钻**：四川省 2020 年全年几乎每月负增长，**7 月、9 月、11 月最差**；
6. **业务归因**：四川出现本地竞品，常年低价 + 大量本地网点 + 线上配送，打破原有竞争格局。

教材建议：评估竞品是否可持续、冲击是否长期；从渠道布局（加大线下门店投入）和供应链/多层次定价两个方向应对，并在执行后持续跟踪复盘。

## 三、Python 迁移思路

| Excel 操作 | Python 等价实现 |
|---|---|
| 数据透视表按年汇总 | `groupby("年份")["收入"].sum()` |
| 同比计算 | `pct_change()` / 同月对齐后相除 |
| 切片器切换年/月/省 | 函数参数化下钻：`yoy_by_month(province=...)`、`province_yoy(...)` |
| 折线图、柱状图 | `matplotlib` 双轴柱线图、分组折线、横向条形图 |

## 四、数据说明

教材只给结论、未附案例数据，本实验按结论反向构造面板数据（固定随机种子 2024）：

- 2017 年全国年度收入约 120 亿元（模拟值），2018 年同比 +14%、2019 年 +11%；
- 2020 年上半年月均同比 +7.2%，下半年降至 +1.0%，11 月全国同比 -0.52%；
- 2020 年 11 月 9 个省份同比为负，四川 -12.4% 最差；
- 四川 2020 年 12 个月同比全部为负，7/9/11 月跌幅最大。

**数据为模拟还原，仅用于复现分析方法，不代表平台真实业绩。**
