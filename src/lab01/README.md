# lab01 同期群留存分析

## 一、教材出处与业务背景

- 教材：第 2 章 2.1.1 分类分析（PDF p43-61），原案例用 Excel 完成。
- 业务背景：某内容产品在 **3 月 8 日** 上线"免费注册"拉新活动，当日新增注册用户 **+32.5%**。
- 业务问题：新增上去了，但这批新用户是不是"薅羊毛"的低质量用户？留存有没有被拖累？后续是否继续投放同类活动？

## 二、教材口径（必须一致）

| 要素 | 教材定义 |
|---|---|
| 群组划分 | 按**注册日期**划分同期群（cohort） |
| 留存观测点 | 注册后第 1、3、5、7 天 |
| 对比方式 | 横向：活动群组 vs 其他群组；纵向：留存衰减曲线 |
| 关键结论 | 活动群组次日留存 **32%**，其他群组 **44%**，整体次日留存均值 **44%** |

## 三、Python 迁移思路

| Excel 操作 | Python 等价实现 |
|---|---|
| 按注册日分组做数据透视 | `groupby("register_date").mean()` → cohort 矩阵 |
| 透视表着色 | `seaborn.heatmap` |
| 折线图对比群组 | `matplotlib` 双折线 + 标注 |
| 新增人数柱状图 | `matplotlib` 条形图，活动日高亮 |

## 四、数据说明（重要）

教材正文写明"案例数据请参看本书附赠的案例源文件"，但 PDF 未附带数据，因此本实验数据为
**按书中结论反向构造的模拟数据，不是原始业务数据**：

- 2/1–3/31 每日自然新增约 800 人（±5% 波动），3/8 活动日 = 800 × 1.325 = 1060 人；
- 其他群组留存：D1 44% / D3 31% / D5 25% / D7 21%；
- 活动群组留存：D1 32% / D3 22% / D5 17% / D7 14%；
- 为便于复现，按"留存倾向分"排序后取固定人数，使各群组留存率精确命中设定值，固定随机种子 42。

## 六、运行结果（与教材对照）

| 指标 | 模拟结果 | 教材值 | 是否一致 |
|---|---|---|---|
| 活动日新增增幅 | +32.5% | +32.5% | ✅ 完全一致 |
| 活动群组次日留存 | 32.0% | 32% | ✅ |
| 其他群组次日留存 | 44.0% | 44% | ✅ |
| 全体次日留存均值 | 43.7%（≈44%） | 44% | ✅ 同口径 |

结论与教材一致：**活动显著拉高了新增，但活动群组的留存曲线整体下移，
次日留存比常规群组低 12 个百分点，说明这波拉新质量偏低**。
建议：优化注册后的新手引导与首日激活，而不是继续加大同类免费注册投放。
